# 쿠팡 실시간 핫딜 봇

쿠팡 상품 가격을 지속 추적해 **평소보다 급락한 상품**과 **당일 골드박스 특가**를
텔레그램 채널에 자동으로 올립니다.

## 구조

| 파일 | 역할 |
|---|---|
| `config.py` | 모든 조절값. 튜닝은 여기만 |
| `coupang.py` | 쿠팡 파트너스 API (HMAC 인증) |
| `store.py` | 가격 이력 DB (SQLite) |
| `scoring.py` | 하드컷 → 점수 → 등급 |
| `notify.py` | 텔레그램 카드 발송 |
| `main.py` | 실행 진입점 |
| `calibrate.py` | 임계값 조정용 히스토그램 |
| `.github/workflows/bot.yml` | 자동 실행 스케줄 |

## 실행 모드

| 모드 | 동작 |
|---|---|
| `auto` | **스케줄 기본값.** 시각 보고 데일리/급락을 자동 선택 |
| `selftest` | 쿠팡·텔레그램 연결만 점검 |
| `hunt` | 급락 감시만. 없으면 발송 안 함 |
| `live` | 데일리 발송 (급락 + 골드박스) |
| `test` | 진단 리포트 (점수·배점 표시, 실발송 아님) |
| `dry` | 콘솔 출력만 |

## 스케줄

```
KST 07:00~22:59  →  20분 간격  (48회/일)
KST 23:00~06:59  →  60분 간격  ( 8회/일)
                     합계 56회/일 = 월 1,680분 (무료 2,000분의 84%)
```

`auto`가 KST 07/12/18/22시 정시에는 **데일리 발송**, 나머지는 **급락 감시**로 동작합니다.
자세한 계산 근거는 `BUDGET.md` 참고.

## 필요한 Secrets

Settings → Secrets and variables → Actions → Secrets

| 이름 |
|---|
| `COUPANG_ACCESS_KEY` |
| `COUPANG_SECRET_KEY` |
| `TELEGRAM_BOT_TOKEN` |
| `TELEGRAM_CHAT_ID` |

> 네이버 키는 더 이상 쓰지 않습니다. `NAVER_*` 시크릿은 남아 있어도 무해합니다.
> `RUN_MODE` 변수도 더 이상 쓰지 않습니다 (`auto`가 대체).

## 판정 방식

기준가 = **그 상품 자신의 최근 14일 가격 중앙값**

| 항목 | 배점 |
|---|---|
| 하락폭 | 40 |
| 자릿수 오류 (`현재가 × 10 ≈ 평소가`) | 20 |
| 판매 인기도 (rank) | 15 |
| 절대 하락액 | 10 |
| 로켓배송 | 8 |
| 골드박스 | 7 |
| 표본 부족 / 수량표기 없음 | −12 / −8 |

발송 게이트: 하락률 30% 이상 **AND** 하락액 15,000원 이상

| 등급 | 조건 |
|---|---|
| S | 82점↑ + 자릿수 오류 → 🚨 가격오류 의심 |
| A | 68점↑ |
| B | 48점↑ (데일리 발송에만 포함) |

## 초기 운영

| 시점 | 상태 |
|---|---|
| 설치 직후 | 골드박스만 발송. 급락은 "이력축적중" |
| **약 6시간 뒤** | 급락 판정 시작 (표본 6개 도달) |
| 약 1일 뒤 | 표본부족 감점 해제, 등급 정상화 |
| 1주 뒤 | `python calibrate.py`로 임계값 조정 |

## 튜닝

`config.py`의 값만 고칩니다.

| 값 | 기본 | 효과 |
|---|---|---|
| `SEND_RATIO` | 0.70 | 낮추면 알림 줄고 정확해짐 |
| `MIN_SAVING` | 15000 | 올리면 소액 딜 제외 |
| `GOLDBOX_SHOW` | 6 | 데일리 골드박스 개수 |
| `HUNT_MAX_CARDS` | 4 | 급락 1회 최대 알림 수 |
| `GRADE_B` | 48 | 낮추면 발송 늘어남 |

한 번에 값 하나씩만 바꾸세요.
